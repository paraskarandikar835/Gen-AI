# GenAI Interview Preparation Platform

An AI-powered interview preparation platform that helps users prepare for job interviews using their resume and job description.

## Features

- User signup and login
- Resume upload
- Job description analysis
- AI-generated technical questions
- AI-generated behavioral questions
- Skill gap analysis
- Interview preparation plan
- Interview report history
- Resume PDF generation

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Google Gemini API
- JWT
- Puppeteer
- Axios

## How It Works

1. Create an account or log in.
2. Upload your resume.
3. Enter the job description.
4. Add your skills and experience.
5. Generate the interview report.
6. Use the questions and preparation plan to prepare.
